# Support

Contribution Compass v2 is currently a rewrite foundation, not a usable recommender. Use
[GitHub Discussions](https://github.com/amirimi/contribution-compass/discussions) for design and
development questions, and GitHub Issues for reproducible bugs or scoped feature work.

Read the [v2 specification](docs/product-spec-v2.md) before proposing product behavior. Report
security vulnerabilities through [GitHub Security Advisories](SECURITY.md), not a public issue.
